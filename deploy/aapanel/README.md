# aaPanel (AuGetway)

Use aaPanel only for **Nginx**, **two sites**, and **SSL**:

- `amarpin.com` → snippet `deploy/ubuntu/nginx-site-snippet.conf`
- `api.amarpin.com` → snippet `deploy/ubuntu/nginx-api-snippet.conf`

App code lives at **`/var/www/amarpin.com`** on Ubuntu (not aaPanel “Node project” or Git deploy).

Full steps: [deploy/ubuntu/README.md](../ubuntu/README.md).
